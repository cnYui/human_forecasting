# JRT 源码与数据复现计划

## 目标

用户要求深度调研论文 `docs/download/2023-joint-relation-transformer-multi-person-motion-prediction.pdf`，将论文源码拷贝到 `/home/rpartx3080/CodeSpace`，并下载用于复现论文代码的数据集。

## 必须先确认的问题

1. 论文全称、作者、会议、任务定义、模型结构、训练/评估协议。
2. 官方源码仓库是否存在，仓库是否仍可访问，license 与 README 是否说明数据准备方式。
3. 论文使用哪些数据集，哪些可直接下载，哪些需要注册、协议或手工申请。
4. 本机复现的最小可行路径：环境、目录、checkpoint/数据路径、训练或评估命令。

## 执行策略

- 以论文 PDF、CVF/openaccess、官方 GitHub 或作者页面为主源。
- 源码目录放在 `/home/rpartx3080/CodeSpace/`，不混入当前 ReGenNet 仓库。
- 数据集下载优先放在官方源码仓库 README 指定位置；如果 README 没有固定路径，则放到源码仓库的 `data/` 或 `datasets/` 约定目录，并记录实际路径。
- 对需要账号、表单、协议或无法公开直链下载的数据集，记录阻塞原因和官方申请入口，不伪造完成。
- 所有调研、命令、下载结果和阻塞项新建结果文档，不覆盖历史文件。

## 验收

1. `/home/rpartx3080/CodeSpace` 下存在 JRT 官方源码目录或明确说明未能克隆的原因。
2. 可公开下载的数据文件完成下载并经过 `file` / `ls` / checksum 或至少大小检查。
3. 对不能自动下载的数据集给出官方来源、所需权限和后续手工步骤。
4. 新建结果文档，包含论文深度调研、源码状态、数据集状态和复现命令建议。
